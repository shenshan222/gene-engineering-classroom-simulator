# 基因工程基本操作课堂模拟器 V2

本目录按照 `gene-engineering-v2-plan.md` 从零实现。

## 当前进度

阶段 1 已包含：

- Vite、React、TypeScript 和 Vitest 项目骨架；
- DNA、片段、末端、限制酶、引物和学习任务类型；
- DNA 序列规范化、互补和反向互补工具；
- EcoRⅠ、MunⅠ限制酶数据；
- 学案活动 1、2、3、4 的固定数据；
- 领域数据与序列工具单元测试。

阶段 2 已包含：

- 线性与环状 DNA 的限制酶位点扫描；
- 限制酶切割和任意位置手动平末端切割；
- 一次或多次酶切后的片段生成；
- 环状 DNA 单切点展开和双切点片段生成；
- 片段翻转及 feature 坐标重映射；
- 黏性末端、平末端和突出链方向判断；
- 插入片段正反方向尝试和双接头连接；
- 学案活动 1、2、4 的领域级回归测试。

学案活动自由画布已包含：

- 活动 1、2、3、4 的紧凑切换和独立实验状态；
- DNA 序列 1、2 及所有切后片段均为自由拖动组件；
- 每个双链碱基对独立渲染，每个碱基间隙可点击；
- 选择 EcoRⅠ后直接点击识别位点完成真实酶切；
- 选择 DNA 连接酶后依次点击两个 AATT 黏性末端；
- 活动 2 的受体环化、环状 DNA 单点切开展开和重新闭合；
- 活动 3 的可拖动单链引物、全部结合位置计算和 PCR 产物展示；
- 活动 4 的 EcoRⅠ/MunⅠ选择、兼容末端和标记基因保护；
- 四项活动各自的自动完成判定；
- 移动、切割和连接的撤销、重做与重置；
- 桌面、触控平板和手机横屏适配。

随机训练已包含：

- 固定学案与随机训练模式切换；
- 活动 1 的线性 DNA 酶切与连接随机题；
- 活动 2 的受体环化、单点打开和重组质粒随机题；
- 活动 3 的随机 PCR 模板、正确引物与典型干扰引物；
- 活动 4 的兼容黏性末端与标记基因保护随机题；
- 四类题均提供基础、标准两档难度；
- 基于字符串种子的确定性随机数，相同种子可复现相同题目；
- 受体、供体、目的基因、酶切位点、PCR 模板和引物的约束生成；
- 独立酶切/连接/PCR 求解器与题目校验器，未通过校验的候选题不会展示；
- 种子输入、复制、重新生成和“下一题”；
- URL 种子恢复与本地偏好保存，教师可以直接复制当前页面地址分享题目；
- 8000 个批量随机种子属性测试，以及四类随机题的真实操作完成测试。

## 本地命令

```bash
npm run dev
npm run typecheck
npm run test
npm run build
```

需要 Node.js 22.13.0 或更高版本。
